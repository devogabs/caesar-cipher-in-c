# Caesar Cipher in C

This is a basic implementation of Caesar's Cipher in C. The goal of this project is to learn C's syntax, as well as the use of for loops, array manipulation, user input and some basic operations.

## Installation & Usage

1. Clone the repo:
```bash
git clone https://github.com/devogabs/caesar-cipher-in-c.git
cd caesar-cipher-in-c
```

2. Compile the code:
```bash
gcc caesarCipher.c -o caesarCipher
```

3. Ready to go! Just run:
```bash
caesarCipher
```

You'll see a CLI like:
```bash
Choose an option:
1. Encrypt
2. Decrypt
```
Then you can choose between Encryption (enter 1) or Decryption (enter 2).

(e.g. entering 1)
```bash
Enter message to encrypt: Hello, World!
Enter shift value: 3
```
Example Output:
```bash
Encrypted message: Khoor, Zruog!
```

That's all for now! Thank you for downloading! :)
